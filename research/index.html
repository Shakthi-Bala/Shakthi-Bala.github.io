Research questions, research and internship experience, teaching, and technical notes.

I work on perception and learning for robots. The questions below come from the failure cases and comparisons in these projects.

Questions behind the work

When should a world model use explicit geometry?

In the occupancy world model, explicit ego-motion warping made a large difference under the same training schedule. I’m interested in where that division stops helping: moving objects, newly visible space, and imperfect pose estimates.

How should a planner treat unobserved space?

The occupancy experiments exposed two related problems: forecasts that leave unseen regions empty, and metrics that confuse missing ground labels with off-road evidence. I want to understand how those unknowns should affect candidate scoring and evaluation.

What can localization retain when stereo matching fails?

On a difficult EuRoC sequence, temporal tracks remained useful while stereo matches disappeared. The VIO work investigates how to retain those observations without adding poorly constrained landmarks. The Deep VIO comparison raises a related question: when does a lower prediction loss actually improve the integrated trajectory?

I’d be interested in comparing failure cases, evaluation protocols, and reproduction results with others working on these problems. The project repositories contain the code and supporting records.
